# CLDR calendar data

Calendar names and full-date patterns are extracted without translation or
modification from Unicode CLDR JSON 49.0.0, commit
`a4b67247b446fd51b475991017a2481911210c60` in https://github.com/unicode-org/cldr-json.
Portuguese (pt) supplies pt-BR; pt-PT supplies European Portuguese.

Source hashes and the reduced data hash are in tests/i18n/CLDR-SOURCES.json.
No data is downloaded at build or run time.
