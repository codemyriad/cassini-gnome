## D52.1: answers to GNOME R63, R64, R65, R67, R69 (Coordinator), 2026-11-01

Written while drmeyers was unreachable; apply to DECISIONS-UX.md, strings.json (from /mnt/ai/cassini/i18n/pending/d52-strings.json) and x-schema.json when it is back.

- **R63 (source-report copy):** approved, with plainer wording for four strings:
  - `details.sources.failed` "{source}: audio couldn’t be recorded."
  - `recording.sourceProblem` "Some audio couldn’t be recorded. Cassini keeps recording the rest."
  - `details.reason.callConnected` "The call connected, so Cassini started recording each person separately."
  - `details.sources.overlap` "Overlapping audio was kept as separate speakers."
  - The rest are as proposed, plus R69's `details.sources.notSelected`. All eleven are published in all six languages.
- **R64 (overlap attribution):** the `base:overlap:n` suffix is approved, with ids as in GNOME's d52-source-grouping.md vectors. Mac uses the same vectors.
- **R65 (portable source record):** optional `recordingDetails.captureRecord`, version 1, is approved. It is carried in `x["codemyriad.io"].meeting`, with future fields preserved and never downgraded. The coordinator adds it to x-schema.json and MAPPING.md, and Mac reads and writes the same shape.
- **R67 (resumable Start for the system stand-in):**
  - The opt-in `resume-capture-v1` protocol capability is approved as a protocol PR: GNOME owns it, Mac reviews it, and the extension version is bumped.
  - Start may target the active stand-in `{captureId, timelineOriginMs}` with the selected callGeneration. A stopped or changed target is refused, and a fresh manual Record is unchanged.
  - Shared tests cover both delivery orders, Stop before Start or session construction, a fresh Record after Stop, stale A/B signals, a retained microphone and selection, and a half-open D49 seam.
- **R69 (unselected sources):**
  - Approved: an optional source-row field `captureExpected: false`, where missing means true.
  - It becomes true permanently once the source is selected or a span opens.
  - Only expected sources flag the recording, and a failed unused source never stops healthy audio.
