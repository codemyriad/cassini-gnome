# D38 synthetic echo corpus

Exact coordination files and hashes are listed in UPSTREAM.json. Source speech is generated by macOS `say` from the committed script; no personal recording is included. Reuse the frozen WAVs rather than regenerating TTS on another OS version.

Run `python3 tests/bleed/make.py /tmp/cassini-synthetic-library` to build a throwaway clean/bleed Library. Run `probe.py BUNDLE OUTPUT --modules INSTALLED_MODULE_ROOT` only in a private offline test container with `CASSINI_WHISTLE_NETWORK_NONE=1`. The existing Whistle CI harness does this automatically. The probe creates its Library below OUTPUT, never in a user's Library.

The shared vectors are proposed in coordination 7249927 and await Mac review. Expected flags are written by hand; the builder lives with the source contract in coordination. Do not regenerate expectations from the classifier.
