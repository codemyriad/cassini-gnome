# Model download core (D4/D15)

Whistle remains bundled. This core does not enable another recognizer, speaker model or Settings row. `ModelStore.download(id, source_sha256)` is an explicit operation: importing the module, opening About, checking installed files and removing a revision make no network requests. A valid installed receipt is reused without even fetching the manifest.

The source is `https://dist.gocassini.com/manifest.json`, schema version 2. Both model ID and source digest are required; there is no implicit latest revision. Each declared artifact uses the immutable `models/files/<compressed-sha256>/<filename>.zst` URL on the same origin. Redirects to another origin, HTTP content encoding, malformed paths and duplicate pins are refused. Production origins cannot be overridden; tests opt into an HTTP loopback fixture.

Partial compressed files and strong ETags live under `$XDG_DATA_HOME/cassini/models/.downloads/<id>/<source_sha256>/`. Resume uses actual file length, Range and If-Range. A 200 replaces the prefix, 416 restarts, and a 206 must have exactly the expected offset, length, total and validator. Missing/weak validators cannot authorize append. A truncated transfer preserves its bytes for a later explicit retry. Completed staged output also survives a failed later file or NOTICE transfer.

Compressed size and digest are checked before decoding. libzstd decodes in 128 KiB blocks, with a maximum 128 MiB frame window, supporting concatenated and skippable seek-table frames. Decoded size and digest must match before publication. The whole checked revision, receipt and distribution notice appear together through a Linux rename with NOREPLACE. Existing revisions are never overwritten. File and directory syncs preserve publication metadata; a per-pin filesystem lock serializes install/remove. No decoded model is written into `/tmp` or a meeting folder.

`plan()` reports download, installed and conservative staging bytes, including bounded notice metadata. Existing checked output and resumable compressed bytes reduce the remaining staging need; a metadata-only retry does not reserve the whole model twice. Before requesting model artifacts, download refuses a plan that would leave less than the recording reserve: the larger of 1 GiB and 2 percent of the destination filesystem. Runtime inference readiness remains a separate concern for the future model feature.

The distribution's NOTICE.txt is fetched as part of the explicit download, included as `.cassini-NOTICE.txt` in the revision (preserving any original model `NOTICE.txt`), and copied to the model store root. About offers “Licences of downloaded models” through the native file launcher only while at least one downloaded model remains (D15.1). Removing weights keeps the small legal notice and hides that link when the last model is gone. No meeting audio, transcript or voiceprint is uploaded.

Tests use a generated, two-frame seekable Zstandard object and a local HTTP server. They cover interrupted transfers, exact resume headers, 416, changed ETags, invalid ranges/weak validators, both bad hashes, disk refusal/write failure, notices, cancellation, concurrent installers, corruption, path/symlink guards, unchanged installed reuse, removal and bounded decoding. CI never uses dist.

Development reference for manifest shape and HTTP rules: gocassini's embedded schema-v2 catalog (`cassini-go-recorder/internal/modelstore/catalogue.json`, source commit `2cc2020118771a0e2ec8dbefcfee1d845853fe78`) and its optional-model-storage documentation. This is a schema reference, not a new speech-model pin; D16 still owns future row/revision selection. A metadata-only live check using the app User-Agent (`Cassini/0.2`) returned HTTP 200: the schema-v2 manifest parsed 12 revisions and 35 artifacts (manifest SHA256 `4b5a255b15ad7bc12d2597542426c0f18b839a7d9e8581bbceb94a03104a0bd3`, NOTICE SHA256 `8a153125fcc23e60ee52ec06a1af64436d568eaef0c8eeffc83c0f365f4621b8`). No live artifact transfer or resume behavior is claimed; those tests use the local fixture server.

Packaging handoff: the core uses the system `libzstd.so.1` stable streaming API (no Python zstandard package or executable). Ensure the platform provides libzstd at runtime. No packaging manifest was edited.
