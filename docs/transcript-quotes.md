# Turn quotation marks (D38.5)

When a turn is displayed, straight double quotes pair in reading order and become “ and ”. A final quote without a partner in that turn disappears. Pairing never crosses a speaker turn. Existing curly quotes and apostrophes stay as written.

Library previews, the Meeting transcript, the standalone transcript reader, Search excerpts and Markdown export use this display projection. The timed items and original transcript files are unchanged. Even when a quote-only item disappears, transcript links and Search seek positions still address the original item.

The formatting tests cover embedded pairs, pairs across timed items, an orphan at a speaker boundary and a quote-only item before a Search match. The Markdown goldens remain unchanged for their existing inputs.
