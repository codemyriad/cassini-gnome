# Cassini for GNOME: technical documentation

These pages describe how the GNOME app implements shared Cassini behaviour.
The user guide is the top-level [README](../README.md); building, testing and
packaging are in [CONTRIBUTING.md](../CONTRIBUTING.md). Cross-app contracts,
decisions (D-numbers) and the shared string catalog live in
`codemyriad/cassini-ux`; the vendored copies are under `ux/` and `tests/ux/`.
