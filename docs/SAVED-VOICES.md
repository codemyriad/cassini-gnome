# Saved voices implementation and validation

UX17 follows coordination D25 and cassini-android `7068c58`. The immutable reference cases and model comparisons are in `tests/ux/voices/`. `UPSTREAM.json` records the copied bytes. The desktop additions keep all native voices of a merged speaker and distinguish `Recording-<uuid>` from `Received-<uuid>`.

CAM++ is an optional, verified dist download. It uses the packaged sherpa fork through its C API in the speech child, with two CPU threads. The UI process imports neither the engine nor NumPy. Extraction follows transcription and attribution; its failure preserves the completed transcript. Both optional models must be On when a new job starts. Historical meetings are not automatically rematched. Merge and Undo can recompute affected prints on the same job executor, preserving typed names and confirmed identities.

`$XDG_DATA_HOME/cassini/voices/people.json` and `meetings/<full-folder-basename>.json` are private app data. Files are mode 0600, directories 0700. A file lock serialises instances. Atomic replacement and a private rollback journal protect multi-file edits; a restart rolls back an interrupted transaction. Newer versions are read-only. Damaged files are retained with a `.corrupt-…` suffix. Forget everyone commits a new generation before cleanup, so older jobs cannot restore prints. Names already written into meetings remain after forgetting. No print, match or audio copy is placed in a Library meeting or exported.

Validation has three layers:

- `pytest tests/test_voice*.py`: the unchanged Android cases plus desktop identity/merge cases, model download and capability lifecycle, store corruption/version/recovery, generation races, cancellation, manual-name preservation, current-Library AUTO/CONFIRMED meeting counts, and optional-model failure.
- `tests/voices/run.sh BUNDLE MODEL_CACHE S11_WAV OUTPUT STAGE`: installed-module tests and three fresh native workers in a read-only, network-disabled, two-CPU container. The test checks all six exact float32 input hashes, 15 cosines within 0.02, exact AUTO/SUGGESTED outcomes, complete worker selection/rejoin against the public S-11 golden, child cleanup, and absence of engine mappings in the parent. With optional Nemotron-cache and Parakeet-model arguments, it also runs the installed production queue with both recognizers, confirming that retry preserves a confirmed print without enrolling it twice. Reports contain hashes and comparisons, never embeddings.
- `tests/ui/voices.py`, `tests/ui/voice-models.py`, and the existing speaker/Library/Meeting checks run through `build-aux/ux-screenshot.sh` with private HOME, XDG directories, bus, display and audio configuration. They exercise real store writes, duplicate-name choices, failure/Retry, Remember, Forget, future-version controls, download cancellation/resume, and model dependency gating. Boards include Speakers, Saved voices and Transcription settings in light and dark schemes at 1120×720.

The model fixture is fetched by `tests/voices/prepare_model.py` through the normal D4 store. Its dist revision, files, compressed artifact hashes and licence are checked before use. CI caches the immutable revision and retains all existing offline, board, source, packaging and capture checks.
