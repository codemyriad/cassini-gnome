# D82 follow-up: package/source tests and package compression

The ten-main-run report is `ci-main-test-timings-20261111.md`. Its five
slowest steps are package builds, with median 520–610 seconds. One Ubuntu
sample spends 319 seconds in four serial pytest shards (83, 67, 73, 96 s).

## Cut 1: bounded two-worker pytest

D68/R91 requires an A/B on one PR, zero flakes over at least ten runs, and a
measured gain before adopting parallel shards. Each shard already owns its
`HOME`, XDG paths and `basetemp`. The ten-pair experiment ran once in CI on
immutable head `01586ab5accc690ccfc910a4305a35d441c3767e`
([run 42979843921](https://github.com/codemyriad/cassini-gnome/actions/runs/42979843921)),
alternating serial (`-Dpytest_parallel=false`) and two-worker
(`-Dpytest_parallel=true`) ordering across ten full Meson suite pairs on one
Ubuntu 26.04 runner (`meson test --num-processes=2`), stopping on the first
failure or coverage difference with no retries:

| Pair | Order | Serial seconds | Two-worker seconds | Delta seconds |
|---:|---|---:|---:|---:|
| 1 | serial → two-workers | 300.969 | 179.621 | -121.349 |
| 2 | two-workers → serial | 295.223 | 177.019 | -118.203 |
| 3 | serial → two-workers | 316.707 | 180.299 | -136.408 |
| 4 | two-workers → serial | 300.477 | 176.900 | -123.577 |
| 5 | serial → two-workers | 308.646 | 183.753 | -124.892 |
| 6 | two-workers → serial | 306.316 | 190.708 | -115.608 |
| 7 | serial → two-workers | 297.779 | 179.848 | -117.932 |
| 8 | two-workers → serial | 299.456 | 178.051 | -121.405 |
| 9 | serial → two-workers | 296.560 | 178.721 | -117.839 |
| 10 | two-workers → serial | 302.940 | 179.050 | -123.890 |

- **Median:** **300.723 s → 179.335 s (-121.388 s, 40.4% less)**; serial range
  295.223–316.707 s, two-worker range 176.900–190.708 s.
- **Zero failures and identical coverage:** all 20 runs passed all 10
  registered Meson tests and produced **5,581 passed, 12 skipped, 0 failed/errored**
  across the exact same **5,593 pytest case identities** in all four shard
  JUnit XML files (`pytest-1..4.junit.xml`).
- **Adoption:** package builds (`debian/rules`, `build-aux/rpm/cassini-talk.spec`,
  `build-aux/arch/PKGBUILD`), `build-aux/check-distros.sh`, and
  `.github/workflows/meson-tests.yml` now configure `-Dpytest_parallel=true`
  paired explicitly with `--num-processes=2`. The Meson option keeps `false` as
  its default so bare local `meson test` invocations on developer or shared
  agent hosts never launch `cpu_count()` concurrent pytest shards. The
  temporary `.github/workflows/pytest-ab.yml` workflow is removed after
  collecting `pytest-ab-ten-pairs`; `build-aux/ci/measure_pytest_parallel.py`
  stays in the tree for reproducible measurement.

A local serial baseline on the Btrfs evidence volume hit the existing 360 s
shard guard; process samples showed repeated waits in `write_all_supers`. The
parallel half was not attempted locally, and the failed local trial was
retained without retry. Timings above are observations, never test pass
conditions.

## Cut 2: required Fedora source dependencies

The Fedora Source step has a 409 s median in the main timing report. DNF's
weak dependencies bring in GPU drivers, media SDKs, portals and daemons that
this headless gate never uses. Source validation now requests required-only
DNF dependencies explicitly. The developer installer keeps its existing
default, and other source images keep their package selection.

Measured fresh containers, pinned Fedora base
`sha256:a7d72ba2745b100a3351087472e5ee7b2450af7cf331e7673007e3817612839c`,
two CPUs, 1.6–2.3 GiB limits, alternating order:

| Pair | Original install seconds | Required-only seconds |
|---:|---:|---:|
| 1 | 47.414 | 23.589 |
| 2 | 45.254 | 35.371 |
| 3 | 43.708 | 37.385 |

Median **45.254 s → 35.371 s**. These are measurements, not pass budgets. Each
variant has identical package versions across all three completed pairs.
Downloads fall from 357 to 252 MiB; installed package count falls from 505 to
364. Every explicitly requested build/runtime package remains.

Both variants pass all ten registered Meson tests: **5,581 pytest cases pass
with the same 12 skips and exactly the same 5,593 case identities**. The real
startup check and every production playback/recording GStreamer element pass.
Excluding the required PulseAudio plugin from a private child-process plugin
path makes the real Source runtime gate fail on `pulsesrc`; the running tests'
plugin environment is unaffected. Proof mutations also reject an unexpected
skip and missing shard JUnit file.

Lower package compression was measured too. Level 19 reproduced the original
Ubuntu package byte for byte; lower levels saved CPU but increased download
size. Required-only Fedora dependencies and bounded two-worker pytest give
larger measured savings without that artifact-size tradeoff; compression
settings stay as they were.
